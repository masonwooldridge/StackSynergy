# StackSynergy rebrand

The user selected1A Classic. The prepared no-text opaque RGB1254×1254 PNG was inspected and deterministically resized with Pillow LANCZOS to1024×1024. The design was not regenerated or redrawn. Web favicons,192/512 icons, Apple touch icon and Expo app/splash assets derive from the same source. The standalone App Store export is public/brand/stacksynergy-app-icon-1024.png. Assets are configured and export-ready; this is not an App Store submission or a native binary rebuild.

Web UI, Expo display name/slug, permission copy, package names and documentation use StackSynergy. Repository target: https://github.com/masonwooldridge/StackSynergy . Local checkout directory stays card-chasm to preserve running tools and paths.

Compatibility is deliberate: local/session storage keys beginning cardchasm-/card-chasm-, database path data/cardchasm.sqlite, native recovery/server-address filenames, API/bridge cardchasm:* messages, and bundle/package ID com.cardchasm.app remain unchanged. Existing account credentials/decks/session records and endpoint protocols are not migrated or reset. StackSynergy adds the stacksynergy deep-link scheme alongside the old cardchasm scheme. New optional environment aliases coexist with existing names; legacy environment variables remain supported. Export/recovery filenames retain their legacy names. These internal names are not a missed data migration.

Automatic approval review rejected a separate proposed rename of recovery/backup filenames and environment identifiers because of compatibility risk; it did not execute. That operation was abandoned. No credential creation/security changes, paid AI, deployment, publishing service or App Store submission was performed. Full trademark clearance is not established.
